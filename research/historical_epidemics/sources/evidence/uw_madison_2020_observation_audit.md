# UW–Madison 2020 观测口径与审计边界

核查日期：2026-10-22。本文件记录数据提供者的说明及本地可验证范围；它不是“数据审计全部通过”声明。主对象为 `uw_madison_2020` 的学生/员工校内每日阳性检测与检测次数。

## 证据与复现入口

- `data/raw/uw_madison_2020.html`：已归档官方仪表板，定位 `Notable events`、`About the Data`、`Testing Results By Day`。
- `data/raw/uw_madison_2021_spring.html`：另一版回溯快照；与2020日表重叠，但不是独立重复样本或逐日修订历史。
- `data/raw/uw_madison_2020_residence_study.html`：本次归档 Currie 等 EID 2021 原文，定位 `Introduction`、`Methods > Epidemiologic Data Analysis`、`Results > SARS-CoV-2 Testing Results`。原始 URL、实际取得时间、字节数及 SHA-256 保存在 `data/download_manifest.json`；来源归入 `sources/records.json` 的 `REVIEW-X01`。
- `sources/manual_context.json`：事件/人口维护入口。经现有离线 `build` 输出 `data/events.csv.gz`、`data/populations.csv.gz`，按 `entity_id=university_uw_madison` 筛选。

## 字段口径

| 字段或范围 | 官方说明及使用边界 |
|---|---|
| `new_positive_tests` | 公开阳性检测计数；不直接等于全校真实新增感染、每日去重感染者或模型首次诊断数 |
| `new_tests` | 检测次数；同一人可重复受检，不是当日/全期去重受检人数 |
| `students` | 本科、研究生/专业学位及 special students；学生雇员和研究生雇员归学生 |
| `employees` | 其他在职 faculty/staff；不含已归入学生的雇员 |
| 校内/校外 | 指检测地点，不代表住在校内/校外；两类不能当住宿分层 |
| 校外报告 | PHMDC只记录阳性者的UW身份，因此无对应校外总检测量、去重受检人数或可计算的校外阳性率 |
| 日历 | 日表保留 `dashboard_date`；没有已核实的、对各指标一致的采样日/结果日映射。研究的宿舍分析明确使用采样日，但未证明它与仪表板各列日期一一对应；不把研究中的平均两天周转时间变成统一日期平移 |
| 7日阳性率 | 最近7日阳性次数求和除以同范围检测次数求和；不是每日百分比的平均，也不是人口感染率 |

## 检测过程及统计修订事件

观测审计新增的8条事件、原先3条接触政策与E0构建补齐的4条事件共同形成15条UW结构化记录。下表中的范围是解释所需条件，不能仅凭一个日期给所有序列机械切段。

| 日期 | 事件类型/事实 | 对分段的含义 |
|---|---|---|
| 2020-08-06 | 首个Henry Mall校园检测点启用 | 检测服务开始；早于2020日表首日，不补造8/6—8/16数据 |
| 2020-08-25 | Ogg Hall、Frank Holt Center增设检测点 | 服务供给变化，不是受检覆盖率 |
| 2020-08-25—31 | 宿舍生入住当日筛查 | 特定住宿人群的集中检测阶段；不能扩展到全校 |
| 2020-09-02 | 开课首日 | 不表示全员到校或全部课程线下；W1内有接触背景变化 |
| 2020-09-07—21 | 本科生被要求限制活动 | 指令仅针对本科生；9/21为公布期限，不等于已核实实际执行和解除日；W1截至9/6 |
| 未单独给出起止日 | 研究描述宿舍生入住后每两周检测，不论症状；全校学生/员工可免费预约；有症状者被要求预约并自我隔离 | 是研究期背景制度，非逐日执行、依从性或精确制度变更记录。结构化日期留空，不用猜测边界 |
| 2020-09-03 | PHMDC校外日数据整合更新 | 影响包含校外报告的图表；不能假定校内日表同样变动，历史回填未知 |
| 2020-09-16 | 学生/员工分类修订；排除过去90日曾在UHS阳性的患者 | 角色与阳性资格定义更新。回填范围及是否按历史日期整体重算未知，不据此宣布9/16以前/以后就是两套已知定义 |
| 2020-09-26 | 部分线下活动恢复 | 保留some限定，不推定全部课程或接触活动恢复 |
| 2020-10-02 | PHMDC结果从UW收到日改为首次报告日；移除43名校内/校外重复计数者 | 针对校外报告时钟与跨来源重复；不是校内采样时钟变化，也不能证明全部重复已消除 |
| 2020-10-06 | Porter Boathouse新增步行/驾车检测点 | 服务供给变化；无逐日受检构成或实际能力记录 |
| 2020-11-30 | 集体授课全线上，并建议本科生留在永久住所至春季开学 | 建议不等于实际离校，不能推算逐日在校人数 |

网页“更新日”进入事件表的 `date_effective`，描述和质量标记明确它是仪表板更新日、回填未知。它不代表所有历史数据定义从该日才改变。原先的9/9宿舍检疫、9/10相关线下授课暂停、9/14远程授课事件保留。

本次未取得可归档的进一步UW检测更新公告，不用未取得原件的“每周检测切换日期”建立正式分段。研究给出的每两周制度也不能证明2020年8—12月全部日期制度不变。

## 受检人数：找到什么，仍缺什么

研究明确报告：2020-08-25—31入住周，宿舍队列6,162名学生中5,820名接受检测（94.4%）。本次将两者各保存一条人口/队列记录：

- `residence_hall_study_cohort=6162`：研究以2020-09-22住房名册界定的19栋宿舍队列，不是每日入住人数。
- `residence_hall_move_in_tested=5820`：入住周区间内的受检学生人数，不是检测次数；不是每日人数，也不是全校受检人数。

这个跨时点队列的已发表比例按原文保留，不能将5,820均分成7天，不能用45,540注册学生替换其队列分母。研究中的症状或人口特征统计若针对阳性者，也不能推作所有受检者的构成。

仍未取得覆盖137日全校的：

1. 每日或全期按学生/员工去重的受检人数；
2. 重复检测频次及跨日受检者关联；
3. 受检者中宿舍/非宿舍、症状/无症状、常规筛查/主动就诊/接触者检测的每日比例；
4. 每种检测路径的实际执行率、依从性、受检概率及其变更日期。

因此只能声称具有“学生/员工的检测次数分层”，不能声称具有完整受检人群构成。注册学生数或员工岗位数不能充当已受检人数；全期检测次数除以注册人数也不是检测覆盖率。

## 审计项的证据等级

| 审计项 | 本地可以核验 | 现有材料不能核验 |
|---|---|---|
| 前向填充/补零 | 重新解析原始HTML，548条数值、日期、单元格定位和原始字符串与规范化表一致；转换器不补日期、不前向填充 | 数据提供者内部是否曾插补/回填，以及具体逐行修订历史 |
| 重复/重复累加 | 日期×人群×范围×指标唯一；两个快照重叠548条一致；不相加累计值、不把重叠快照叠加 | 未公开的个体重复检测及上游去重是否完整；90日规则不等于终身只计一次 |
| 日期错位 | HTML日期原样保留；连续137日；不机械平移；校外报告时钟修订有出处 | 校内阳性和检测量每一天各自的采样/结果/报告时钟完全匹配，以及上游更正全量历史 |
| 检测制度分段 | 可标记有出处的检测服务变化、入住周、统计修订及接触政策 | 缺失的执行记录、精确切换日和全部历史回填；“没有事件”不能证明制度稳定 |
| 分母与受检构成 | 有学生/员工检测次数及宿舍入住周有限受检人数 | 全校每日去重覆盖与筛查路径/症状构成；不能据此把样本阳性率当总体感染率 |

日表与网页 `Total` 的差异也未消除：学生为7次阳性/242次检测，员工为3次阳性/443次检测。保留原值，不以缩放或分摊配平。

137日日行合计为学生3,704/136,584、员工230/20,582，页脚分别为3,711/136,826和233/21,025。W1日行合计学生584/16,677、员工5/1,637，总589/18,314。8/17只有学生为零检测，员工仍有1次；8/24两组均为零。原表零阳性保留，零检测日的率未定义，不能用它推断零感染。

## 对E0设计的约束

以下以用户选定的[E0研究与构建计划](../../e0_calibration_research_plan.md)为准；它更新此前分组阳性率主目标的设计，不改变上文的来源事实和未知项。UW是后续所有基准的目标场景，本次仅实现独立E0；旧控制协议、旧产物加载器和控制人口不随本次修改。

- 主目标为学生和员工相加的**总阳性累计曲线**。逐世界累计平方误差除以W1最终观测总阳性589的平方，再取世界平均；不设分组损失权重。周合计平方误差是预注册敏感性，阳性率、分组曲线和日残差作诊断，不重复加入主损失。
- 0/1/2天输出日期偏移分别拟合beta并比较残差。偏移是待比较的观测映射假设，不是已核实报告延迟；只在观测适配层应用。三个偏移都固定21个比较日期，窗口前待报告队列为空作初始条件，尾部越窗结果独立保存。阳性与实际受检量必须同批平移。
- 人口69,457及31,650本科、13,890非本科学生、23,917员工是按计划采用的精确合成映射；员工/岗位、年份和学生雇员去重仍未解决。教师1,150、职员22,767为模型设定，不能称已核实自然人数或真实年龄分布。
- 本次仅W1主场景及单因素初始感染10/100、症状检测权重20/200和周合计损失敏感性；不做W2/W3、合成恢复或交叉3×3。1SE候选集合仅作描述，不称beta置信区间；模拟分位带仅表达声明机制下的随机性。
- 模型必须输出同角色、同观测资格的检测阳性率，并明确实际模拟检测次数。若模型检测次数与输入不同，必须记录原因，不能仍用历史分母给模拟阳性数强行造率。模型若只有首次诊断数，不能直接称为阳性检测数。
- 改用总阳性累计误差或查看阳性率都不能消除选择偏差、重复受检依赖、未知时钟或90日资格变化；不会增加人数或受检构成证据。
- 不用独立二项抽样解释重复检测；不把检测次数当独立人数计算人群覆盖或个人感染风险。模拟区间仅反映已声明观测机制下的随机性，不覆盖未知受检选择偏差。
- 政策日/制度日分别标记；仪表板更新日只作潜在断点与窗口解释依据。W1包括入住和开课背景变化，不能宣称其接触结构和检测制度已证实稳定。
- 累计或周聚合可以减少日波动，不能修复定义或时钟不明；结果限于所声明观测机制下的参数锚定与条件一致性检查，不能宣布预测验证、外部验证或因果防控结论通过。
