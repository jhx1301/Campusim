**CEMAS 推荐实施协议 v1（2026-10-12）**

一致性审查完成日期：2026-10-13。以下数值是推荐设计，不是已经执行的实验结果。

本协议将[确认清单](llm_preimplementation_checklist.md)中的待定设计收敛为具体建议。配套[机器可读配置](control_protocol_v1.json)是研究方案数据，现有控制器尚不能直接执行。用户已授权由助手设定动作维度和离散强度，原 plan 的“已商定档位”由本文参数表替代。

采用原则：复用现有疾病内核；公平的部分可观测控制任务；中等规模联合动作；公共信息与私有奖励隔离；使用原始结果讨论权衡。容量、档位及活动人天是公开的**合成基准设定**，不宣称真实单位成本、医学最优方案或现实政策建议。未经拟合、计时或调用取得的结果不填成已完成事实。

**1．主要决策与理由**

| 事项 | 推荐决定 | 理由 |
|---|---|---|
| 人口 | 校园和两城市均12,000个实际代理，pop_scale=1、rescale=False | 控制计算量，去除规模转移和动态缩放混淆 |
| 时域 | 起始112个实际日步，day 0–111，16次周决策；Covasim n_days=111 | 可提供多周闭环，明确day 0不会多算一天 |
| 初始感染 | 每回合30，公开总数、隐藏身份 | 隔离传播强度影响；与初始感染同时变动会增加解释困难 |
| 疾病机制 | 单一wild变异，use_waning=False，无疫苗、无外部输入 | 先建立清楚的SEIR式单波控制任务，保证独立感染人数与事件数可对账 |
| 源域变化 | beta相对校准中心U(0.85,1.15)；静态筛查容量从2%/5%/10%人口日容量等概率抽取 | 控制必要异质性，所有可解锁档位先在源域可用 |
| 动作 | [T,S,C,E,A]五维，3×4×3×3×3=324组合 | 教学和其他活动独立控制，支持多种权衡，同时可完整枚举 |
| 在线观察 | 已交付公共记录、4周历史、当前动作/容量/mask | 共同部分可观测任务，排除真实感染、R_e和传播层 |
| 切换 | 每周自由切换，首版无最低保持和升降幅度限制 | 不把旧LLM专属护栏带进比较；切换和强度变化单独评价 |
| 目标 | 真实新增感染+四类负担的固定尺度负增量，lambda=1、gamma=1 | 对应有限时域的未折扣目标；无需虚构美元成本 |
| 主评价 | 分项原始指标、区间、配对差和权衡；无CPBU总体排名 | 不以自定综合分数支持笼统优越结论 |

H在最终测试前通过第12节源域终点检查，若需统一延长到140/168天，则同步修改全部控制器的时域、资源参考尺度和训练；不能只改某方法。

**3．五维动作与精确档位**

固定向量顺序为[T,S,C,E,A]，索引从0开始。T为病例相关检测，S为普通筛查，C为接触追踪，E为学校教学限制，A为工作/机构和社区活动限制。

**T：临床及检疫检测，3档。**

| 档位 | 有症状symp_prob | 普通无症状asymp_prob | 症状检疫symp_quar_prob | 无症状检疫asymp_quar_prob |
|---|---:|---:|---:|---:|
| T0 | 0.08 | 0 | 0.25 | 0 |
| T1 | 0.14 | 0 | 0.50 | 0.03 |
| T2 | 0.22 | 0 | 0.80 | 0.08 |

继承旧P0/P2/P4的主要检测概率，并取消普通无症状概率检测，普通无症状人群由S控制，避免绕过筛查容量。quar_policy固定start，检疫检测对象是进入检疫次日的人。概率只生成请求，实际执行共同受临床日容量0.02N约束；优先症状检疫、其他症状、无症状检疫进入检测，组内独立世界随机抽样。未执行请求当日失效，后续按当日规则重新申请；记录请求/执行/未满足量。症状是模拟执行对象，中央控制器不获得真实症状总量。

两条检测路径固定敏感度0.95、失访0、报告延迟1天；不另加入流感样症状过程或采样等待分布。测试参数是合成基准假设，不能解释成真实检测技术已验证性能。

| 档位 | 每日请求人次 | N=12,000时 | 含义 |
|---|---:|---:|---|
| S0 | 0 | 0 | 关闭普通筛查，保留T与病例处置 |
| S1 | 0.02N | 240 | 低强度配额筛查 |
| S2 | 0.05N | 600 | 中强度配额筛查 |
| S3 | 0.10N | 1,200 | 高强度配额筛查 |

请求量和外部可用容量分开；只有请求≤当前容量的S档合法。源域三种容量下分别有162、243、324个合法联合动作。首版S只改变配额，不同时改变不同人群的周期，避免把“资源增加”和“筛查优先级重设计”混在一起。

使用公开学校参与者、非学校工作参与者、其他人口三组不重叠分层，按人数比例分名额；组内优先最久未筛查者，首次未筛查优先，固定打破并列的世界随机规则。排除已知确诊者、当日已临床检测者、t−3至t−1两条路径任一实际受检者；同人每天最多检测一次，不能复用旧last_screen_day<3的近似。不足组名额重分给其他有候选组，候选不足则留空记录。无欠单队列，未抽到者后续仍因最久未筛查优先。

**固定处置与共同规则。**

隔离/检疫不另成第六动作：确诊隔离至引擎规定恢复日、接触者检疫至调查日+14；每天记录实际处置状态。最低参照=[0,0,0,0,0]，称最低干预；最高参照=[2,最高资源合法S,2,2,2]。全部方法使用相同执行器，没有基于真实感染或模型自报risk的护栏。

每7天可自由改变全部维度。无额外组合禁配，高追踪低检测效果有限属于结果而非物理非法。非法格式/越界/资源非法不执行：先保持当前组合；若当前S因容量下降非法，将S降为最高合法档，其余维保持，记录错误和调整。所有合法资源状态都有S0及合法保持替代。

编码id=((((t×4+s)×3+c)×3+e)×3+a)，范围0–323。LLM JSON仅含action和reason两个必填字段：action为长度5的普通整数数组（拒绝布尔/浮点/越界），reason为非空单行字符串、≤120字；额外risk或policy_id字段拒绝。RL输出id，阈值/参照输出向量，均进入同一校验和解码路径。

**4．公共观察、时序和数值表示**

决策日0、7、14…105；day0历史为空，初始感染30是公开任务常量，不填成诊断。每次只读截至前一日已经交付的记录。4个完成周按最旧到最新排列，左侧零填充和week_valid掩码。每周包含交付诊断、实际临床/筛查检测、交付通知、隔离/检疫/并集人天、学校/工作/社区限制人天、已执行动作、当时资源。当前上下文提供日/时域、公开人口及活动对象、共同五年龄段(0–16/17–23/24–30/31–60/61–99)登记人数与占比、当前动作与各维持续时间、当前容量、前一日已知处置人数、324位合法mask。

原始记录先建立公共ledger，LLM、阈值和RL的字段来源一致。Covasim new_diagnoses当前按采样日计未来阳性，known_contact也可能提前设置，二者均不能直接当交付记录。每个日步结束后记录当天实际到达诊断/通知和处置；执行器当天按到达事件处置，中央控制器要到下一次决策才看到截止前一日的记录。不改变传播核心日内顺序。

| 数值 | RL编码 |
|---|---|
| 周诊断 | D_week/N |
| 检测、通知人次 | count_week/(7N)，不裁剪 |
| 隔离、检疫、并集 | person_days/(7N) |
| 各活动限制 | person_days/(7N_target)，无目标填0+target_valid |
| 当前已知处置 | count/N |
| 资源 | daily_capacity/N |
| 时间/持续时间 | day/H、held_days/H |
| 动作 | 五维one-hot，共16位；资源mask单独提供 |
| 增长 | g=log2((D_now+1)/(D_prev+1))；RL再除log2(N+1) |
| 诊断/检测代理比 | D_week/T_week；T=0填0+proxy_valid=0 |

增长须两周都有效，首周填0+growth_valid=0。LLM显示原始计数和率、公式与有效标记，避免把首周无历史当“稳定”。人次或报告错位可使某些比率超过1，保留实际值。使用固定人口尺度，不以目标数据fit min/max或VecNormalize，不新增R_e或传播层估计器。

隐藏感染、病程状态、beta抽样、真实R_e、传播日志、未来队列、seed/低中高隐藏标签及真值奖励不进入观察、prompt、检索或反馈。episode_id只在runner/日志，不给控制器。训练器获得私有reward；冻结策略只消费公共观察，测试可读info无奖励真值。执行器可内部使用个体索引和模拟疾病状态完成干预，不回传真实病例构成。

**5．计数、人天与目标**

日检测T为实际人次，两路径分别记，再求和；同人每天只执行一次。通知L为实际交付人次，同日去重、跨日重复可计。Q为日终isolated|quarantined并集人数之和，每天重叠只计一次，分项另外保存。

活动A按预先公布的**名义活动时间预算**计，不从beta反推：

- 只参加学校者：学校0.8、社区0.2；只参加工作机构者：工作0.8、社区0.2。
- 同时学校/工作者：各0.4、社区0.2；两者均无者：社区1.0。
- 校园学校名单取class_groups_ug/gr中students和teachers并集，工作名单取lab_groups中students和teachers并集；不能从reset时为空的clu/clg/of边取名单。hybrid学校年龄固定[6,22)、工作年龄[22,65)，使用与生成网络相同的登记成员，不按当天边端点改变名单。筛查按学校优先、非学校工作、其他形成互斥分组，活动预算允许同人学校/工作重叠。权重固定，每模型日同一名义日程，不引入周末/学期日程，是合成活动代理。
- 每日a_i=w_school×E限制比例+(w_work+w_community)×A限制比例，按人求和；学校/工作/社区分项独立保存。每人每天预算总和1，A在[0,NH]。
- Q代表处置运营负担，A代表公开活动政策扰动；同人重叠时两维均报告和纳入各自代理，不称它们为可直接加总的真实货币成本。

I为模拟开始后新增感染事件，初始30另列；无再感染/无外部输入时独立感染与累计事件含初始应一致且≤N。每日流量→周流量→终点累计可对账，禁止读取未finalize的cum_*差分。终点cum_infections=30+sum(new_infections)。

主奖励：
r_k=-[ΔI/N+lambda/4×(ΔT/(0.12NH)+ΔL/(0.10NH)+ΔQ/(NH)+ΔA/(NH))]。

S_T=临床参考0.02N+筛查参考0.10N乘H，S_L=参考通知0.10N乘H。通知参考不是索引调查容量的换名，而是单独合成归一化尺度。H=112时S_T=161,280、S_L=134,400；尺度恒定，不随当期容量/城市/参评结果改变，允许工作量超参考且不clip。四负担等权、lambda=1是公开偏好假设，不代表真实价值相等。lambda=.5/2做对应源域开发后的校园小规模敏感性；切换没有主奖励惩罚。

gamma=1，有限H自然结束为task terminal，不bootstrap；runner崩溃/中断不是正常terminal，不作为完整结果。4周历史和剩余时域是共同近似信息，任务仍为部分可观测，不声称有限历史恢复Markov性。首版用MLP，不额外增加循环网络。

**6．E0：保留证据边界的校准方案**

数据是公开报告/大学摘要重建的聚合序列，特别是daily tests是重建输入。[data说明](../data/README.md) E0主要提供“重建诊断序列的拟合与计数核查”，不能声称官方原始逐日记录或真实城市预测验证。

优先只校准beta∈[.005,.04]，固定层相对系数与人口/病程。beta及所有层倍率同时拟合存在尺度冗余，短序列不支持将它们各自视为独立可识别真实参数。用100个Optuna trials，每个候选同3个校准世界求日诊断MSE平均，再除(观测日均值+1)^2；固定归一化，取消额外R_e惩罚。实际R_e只可事后诊断，不作为新的观测拟合证据。

主拟合窗口2020-08-03至08-18；采用既有t18的人口生成设置、重建daily_tests的test_num、敏感度.95/失访0/延迟0。延迟0是旧序列采样/报告日期无法分开的明确近似，控制实验则使用固定1天延迟，二者分别记录。若获得准确报告日资料，重新校准/版本化；不擅自移位数据以改善曲线。

**9．PPO、DDQN与阈值的实施初值**

初值是有限源域开发起点，不保证收敛，若需改动只能源域验证并在测试前冻结。

| 项目 | MaskablePPO | Double DQN |
|---|---|---|
| 网络 | policy/value各128×128、Tanh | Q网络128×128、ReLU、324输出 |
| 优化 | Adam、lr=3e-4 | Adam、lr=3e-4、SmoothL1 |
| gamma | 1 | 1 |
| batch | 64 | 64 |
| 数据/更新 | rollout256、10 epochs、单env | replay50,000、warmup512、每周步1次更新 |
| 关键项 | GAE .95、clip .2、entropy .01、value .5、grad norm .5、target_KL .03 | target每512步hard update、grad norm10、epsilon从1线性至.05，前半预算衰减 |
| 评估 | deterministic=True，显式合法mask | greedy、epsilon=0，显式合法mask |

PPO使用现成MaskablePPO、mask内置环境，验证回调也使用mask-aware实现；并行时不能只用父进程ActionMasker。[官方说明](https://sb3-contrib.readthedocs.io/en/master/modules/ppo_mask.html) DDQN明确在线网选合法argmax、目标网取其值，随机探索/贪心/bootstrap三处mask，replay存next mask；不把vanilla DQN改名。[Double DQN原论文](https://arxiv.org/abs/1509.06461) 网络输入是公共历史/上下文；不加入真实reward历史或真值info。

阈值用x=周交付诊断/人口×1000，g为公共增长，z=x×clip(2^(g/2),.5,2)；增长无效时g=0。T/C/E/A的两边界分别为(1,5)、(.5,3)、(5,15)、(3,10)，S三边界(.5,3,10)。每维整组边界乘独立loguniform(.5,2)系数，迟滞比例候选.5/.75；升档直接按z，降档须最近2个有效周z均低于当前档进入边界×迟滞。历史不足不降档；资源非法的S立即共同投影到最高合法档。

按固定采样seed82001生成32候选，验证A九世界筛选前4，验证B十八世界选唯一参数；统一最小化同lambda的未折扣正感染/负担cost（等价最大化return）。并列先选活动负担较小、再固定candidate_id。迟滞属于阈值算法，不是全体方法必须服从的外部护栏。

**10．运行预算与收敛检查**

4个完整source episodes计时，分别报告首次JIT、稳态仿真、梯度更新、内存和推理成本；使用指定Python环境CPU起步，单env验证通过再考虑独立进程。不安装依赖或开启训练属于本次文档交付的事实，实施时新增依赖按用户工程规范授权安装并锁定实际兼容版本。

主RL每算法3训练seed，初始8,192周决策步/seed，每2,048步验证A；在全部checkpoint中按验证A正cost选前2，再用验证B最小化同正cost选最终模型，不选最好训练seed代表算法。8,192×6=49,152周步=344,064模拟日，N12k对应大量agent-days；不能把30,000周步当廉价默认。阈值32×9+4×18=360个验证回合，H112时40,320模拟日，成本同样记录。

预算层级8192/16384/32768。source验证在三个训练seed上先平均正cost，最近两checkpoint相对改善=(旧cost−新cost)/max(旧cost,1e−12)，≥2%视为尚未平台；可在pilot冻结的资源上限内升一级，全部该算法训练seed采用同档预算，PPO/DDQN有相同可用上限，实际用量分别披露。到上限仍未平台则报告训练不足，不能据此声称LLM优于充分训练RL。缺少实测耗时不得写成已能在多少小时完成。

lambda=.5/2各需对应RL/阈值重新源域开发并冻结，LLM换相同公开偏好；这会增加训练量，作为独立附录预算，不假装只增加几个测试回合。第二LLM仅两条件，不做全因素矩阵。

依赖采用指定Python3.11环境；基础仿真已可发现，但Optuna、torch、gymnasium、SB3、sb3_contrib、sentence_transformers尚缺。MaskablePPO来自与SB3一致发布版本的sb3_contrib；安装时依据官方兼容约束生成实际lock，不预填未验收的torch/CUDA组合。凭据由本地环境提供，不进配置或公开日志。

**12．终点、统计与失败处理**
