**逐条作者回复——中文版**

以下回复使用可独立阅读的表述，区分已完成修改与仍需开展的实验。编号与[英文版](rebuttal_v1_en.md)一致，核查记录见[证据文档](rebuttal_v1_evidence_and_next_steps.md)。

**审稿人 eojL**

**eojL-W1：缺少更强基线、无记忆 LLM，以及已有 LLM 疫情系统的比较。**

**回复：** 我们已加入两种强化学习方法 PPO 和 Double DQN、可通过实验选择参数的阈值方法，以及不额外提供历史摘要或检索案例的 LLM。各方法获得相同的可观测疫情记录，并从相同的干预组合中决策。完整训练和正式比较尚未完成，与已有 LLM 疫情系统的比较也仍缺失，因此目前不能证明 LLM 优于这些方法。

**eojL-W2：优势依赖作者选择的权重，归一化可能掩盖差异。**

**回复：** 同意，原 CPBU 排名不能支持一般性的优势结论。修订后的评价在比较前固定感染和干预负担的换算尺度，也不再把超过参考尺度的结果截到同一上限。同时，将分别报告感染数和各项干预负担，避免仅凭一个总分判断优劣。不同权重下的比较结果尚未完成。

**eojL-W3：缺少校准拟合、误差指标和样本外验证。**

**回复：** 当前已有 2020 年 8 月 3—18 日的观测与模拟日诊断曲线。20 次独立重复模拟中，平均绝对误差和均方根误差的均值分别为 5.578、11.223。但这些日期也用于校准，只能说明重复模拟对已有数据的拟合情况，不能证明对未参与校准日期的预测能力；后者仍需补充验证。

**eojL-Q1：实际使用哪个 LLM？更换模型后是否仍成立？**

**回复：** 保留的补充材料将 deepseek-v4-flash 列为默认模型，但旧表实际使用的模型仍需通过保存的 API 调用记录确认。修订版本指定 deepseek-flash 为主模型，并计划使用 qwen3.5-plus-2026-02-15 进行第二模型比较。该比较尚未完成，因此目前不能声称结果不依赖模型选择。

**eojL-Q2：能否加入相同任务的强化学习，或相同优化预算下的阈值调优？**

**回复：** PPO 和 Double DQN 已使用与 LLM 相同的可观测信息和 324 种干预组合。阈值参数也将在专门用于调参的模拟中，按与 LLM 相同、同时考虑感染和干预负担的标准选择。目前尚不能说明各方法使用了相同的调参预算；完整训练、正式比较及实际资源消耗仍需补充。

**eojL-Q3：哪些权重下 LLM 仍然更优？**

**回复：** 目前还不能给出这一范围。计划比较的目标为“感染成本 + λ×干预负担”，其中 λ 取 0.5、1、2；λ 越小，越重视感染控制。每个权重下都需要重新选择基线参数，并向 LLM 提供相同的偏好，再比较结果。这些实验尚未完成。

**eojL-Q4：给出校准拟合，并解释两张表相同条件下的数值差异。**

**回复：** 当前校准报告已提供观测与模拟曲线，20 次模拟的平均绝对误差、均方根误差均值分别为 5.578、11.223。旧表之间的差异仍未查明。新实验中，主比较和记忆消融在条件相同时将直接使用同一批模拟结果，避免分别运行造成无法解释的数值差异。

**审稿人 SSFu**

**SSFu-W1：同一模拟器内的评价不能证明真实世界泛化。**

**回复：** 同意。拟合一次真实疫情，再在同一模拟器中评价政策，不能证明政策对真实人群有效。我们计划在不改变已选参数和历史案例库的情况下，将方法用于年龄分布、接触网络不同的模拟人群。实验尚未完成；即使成功，也只能说明方法能够适应不同模拟设置。

**SSFu-W2：需要更强的非 LLM 方法，才能证明 LLM 的价值。**

**回复：** 我们已加入 PPO、Double DQN 和可优化参数的阈值方法，三者与 LLM 使用相同的可观测信息和干预选择。目前仅检查了程序能否正常运行，并完成了少量训练，尚不足以比较控制效果。LLM 是否带来额外收益，仍需完整实验回答。

**SSFu-W3：评价目标和不鼓励线上教学的提示词可能偏向 LLM。**

**回复：** 修订后的提示词已不再要求 LLM 避免线上教学，而是让其同时考虑感染和干预负担；阈值调参和强化学习也使用同一评价目标。改变干预措施本身不额外扣分。这消除了提示词中的明确偏好，但仍需正式比较和不同权重实验检验结果。

**SSFu-W4：校准和敏感性分析的 R_e 范围不一致。**

**回复：** 旧校准代码会在 R_e 超出 [1.5,3.5] 时增加拟合损失，但并未禁止这些值出现。因此结果可以超过 3.5，但这还不能说明论文中 4.52—6.71 的具体原因，仍需核对其计算方法和日期范围。修订后的校准已取消这项额外限制，直接拟合日诊断数据。

**SSFu-W5：记忆消融的收益可能来自更长的严格干预。**

**回复：** 更长干预可能正是记忆发挥作用的途径，因此不能仅据此否定记忆的整体效果。原实验能比较启用记忆后的整体变化，但不能说明相近代价下是否控制得更好。我们将补充无记忆但延后放松的对照，并在相同教学限制总量下比较执行时机，分别检验简单持续控制和更有效决策的作用；这些实验尚未完成。

**SSFu-Q1：R_e 如何定义？为什么超过校准范围？**

**回复：** R_e 表示在当时人群易感水平和干预条件下，一名感染者平均造成的新感染数。旧校准的 [1.5,3.5] 仅是增加超界损失的目标，并非强制上限。后续 E0 将固定估计方法和早期比较时段，根据同期疫情数据、适用研究及估计不确定性，确定该时段平均 R_e 的参考范围。有充分依据时，才将其作为参数接受条件，并用独立重复模拟复核；未通过检查的结果不作为校准成功报告，也不截断超界数值。该范围仅适用于指定校准条件，不能作为改变传播强度后各情景的共同上限。

**SSFu-Q2：阈值如何调优？是否与 LLM 使用相同目标？**

**回复：** 修订版本将在不参与最终测试的模拟中比较 32 组候选阈值，先筛选候选，再通过另一批独立模拟确定参数。选参依据是预先规定的感染与干预负担目标。相同目标及权重也写入 LLM 提示词，指导其选择干预，但不用于训练或微调 LLM；我们不会将提示词中的要求视为模型已实现最优决策的证据。这项阈值调优尚未执行。

**SSFu-Q3：CPBU 权重变化后结论是否成立，尤其更重视感染控制时？**

**回复：** 同意，原 CPBU 排名不能证明 LLM 总体更优。修订后的评价不再使用 CPBU 排名，而是分别报告感染数、检测量、隔离检疫人天以及教学和活动限制，明确呈现各方法的收益和代价。如果某一基线的感染数更低，将如实报告这一优势，不再以综合分数支持 LLM“总体最优”的结论。

**SSFu-Q4：全局记忆如何构建？是否包含与评价相同的场景？**

**回复：** 计划在 27 个模拟疫情中分别采用最低干预、资源允许的最强干预、随机可执行干预和调优阈值，共形成 108 条历史记录。部分传播和资源设置与校园主实验相同，但案例库和测试使用独立生成的疫情，不复用同一条轨迹。因此，这检验的是已知设置下的新疫情。正式案例库尚未建成。

**SSFu-Q5：感染下降有多少来自记忆推理，有多少来自更长干预？**

**回复：** 更长干预可能是记忆发挥作用的途径，现有结果不能自然拆成“推理”和“时长”两个贡献比例。我们将保留自由决策的整体比较，并补充无记忆但延后放松的对照，以及教学限制总量相同、只允许选择执行时机的诊断实验。前者检验简单持续控制能否复现收益，后者检验同量教学限制下的时机选择是否更有效。感染结果和各项干预负担将分别报告，不将差异直接解释为模型内部推理的独立贡献。

**AI review**

**AI-W1：累计感染数超过所述人口。**

**回复：** 根据已核实的记录，尚不能用论文所述人口和单次感染设定解释 51,651 这一数值。修订版本明确模拟 12,000 人，每个模拟个体代表一人，不允许再感染，也不引入外来病例。因此，初始 30 人与后续新增感染之和必须不超过 12,000。旧感染总数仍需从原实验记录重算。

**AI-W2：CPBU 的归一化、权重和缺少不确定性使排名不可靠。**

**回复：** 同意，原总分不足以证明可靠的总体排名。修订后的评价将分别报告感染数、检测量、接触通知量、隔离检疫负担和活动限制，在相同模拟条件下逐一比较，并给出差异的置信区间。同时还需比较不同权重下的结果。这些分析尚未完成，因此目前不能声称总体更优。

**AI-W3：缺少模拟器准确性及宿舍、课堂主导传播的直接证据。**

**回复：** 当前报告已比较观测与模拟日诊断，20 次模拟的均方根误差均值为 11.223。但这只反映对校准时段的拟合，不能证明更广泛的预测准确性，也不能说明感染主要发生在哪里。“宿舍和课堂始终主导传播”还需要直接统计各场所造成的感染，目前尚未报告这类结果。

**AI-W4：未充分区分已有强化学习控制和带记忆的 LLM 方法。**

**回复：** 同意，利用强化学习选择疫情政策、利用记忆辅助 LLM 决策均已有先例，包括 [Mai 等](https://www.ijcai.org/proceedings/2023/682)、[Meirom 等](https://proceedings.mlr.press/v139/meirom21a.html)、[RAFA](https://proceedings.mlr.press/v235/liu24ab.html) 和 [DiLu](https://proceedings.iclr.cc/paper_files/paper/2024/hash/93c936b9e492def9c00782cab79dbc6d-Abstract-Conference.html)。我们的贡献应限定为：在校园任务中，根据可观测疫情信息和历史案例选择可执行干预，并在统一条件下与其他方法比较其价值。目前这部分比较证据仍不完整。

**AI-W5：记忆收益与更大的干预强度混杂。**

**回复：** 更长干预可能是记忆带来的决策变化，本身可以构成记忆的整体效果，但不能证明相同代价下控制更有效。现有最强干预参照也不能保证负担相近。我们计划增加无记忆但延后放松的对照，以及等量教学限制的诊断实验，分别检验简单持续控制能否复现结果、同量限制下时机选择是否更有效，并同时报告其他干预负担。

**AI-W6：未分开检验两类记忆，也未直接测量策略稳定性。**

**回复：** 我们已实现四种设置：不增加额外记忆、仅提供近期历史摘要、仅检索历史案例、同时使用两者。四者保留相同的基础四周观察、模型设置、专家知识和输出要求，但效果比较尚未完成。专家知识是否提高稳定性，也需单独比较有无知识时实际发生的干预变化，不能只依据感染曲线判断。

**AI-S1：清楚定义观察、动作和反馈。**

**回复：** 修订任务明确每七天决策一次。控制器根据已报告诊断、检测、过去干预和当前资源，在临床检测、筛查、追踪、教学限制及其他活动限制的 324 种组合中选择；随后获得实际执行情况和相应负担记录。隔离、检疫按固定规则执行。论文仍需用一张紧凑表格列出各干预档位的具体参数。

**AI-S2：分析非法输出、回退、误导检索和决策失败。**

**回复：** 我们已记录模型输出能否被正确读取、措施是否超过资源限制、提议失败后实际执行了什么，以及检索到了哪些历史案例。这些记录可以支持所要求的分析。但错误发生比例，以及误导案例、过早放松和过度限制的具体例子，仍需从完整实验中汇总并检查。

**AI-S3：用不同的建库和测试条件检验泛化。**

**回复：** 我们计划先用校园模拟建立历史案例库，在测试前固定其内容，再用于年龄分布和接触关系不同的人群，且不把测试案例加入库中。实验尚未完成。仅在同一校园设置下改变随机初始化、多运行几次，不能证明方法能够适应不同传播规律或外来病例输入条件。

**AI-S4：区分模拟器贡献与控制器贡献。**

**回复：** 模拟器负责提供干预能够实际影响疫情的实验环境，控制器负责根据可观测信息选择干预。与真实诊断曲线相符，只能为模拟器提供有限支持；不同政策的比较则用于评价控制器。标题、摘要和结论应分别说明这两部分，避免用政策结果证明模拟器准确复现了真实校园。

**AI-M1：“从不使用线上教学”与 1.4 天矛盾。**

**回复：** 同意，该表述与表 1 矛盾。应准确写为“表 1 报告 High 条件下平均使用线上教学 1.4 天”，而不是“从不使用线上教学”。这一计数本身仍需与原实验记录核对。

**AI-M2：“Daily quarantine”缺少明确单位。**

**回复：** 应区分某一天的检疫人数和累计检疫人天：一人检疫三天计为三人天。日均检疫人数则等于累计人天除以模拟日数。表头必须明确报告哪一种；合并统计隔离和检疫时，同一人同一天只计一次。

**AI-M3：首次决策时，记忆公式无法计算。**

**回复：** 首次决策尚无完整周记录，修订后的实现会明确说明历史和趋势不可用，不计算空历史的加权平均，也不把缺少历史解释为零感染或疫情稳定。

**AI-M4：零向量、常数趋势和过短序列缺少处理规则。**

**回复：** 修订后先按固定尺度换算观测值，再直接比较数值差异，不再除以向量长度或趋势方差，因此零值和常数趋势仍可处理。少于两个完整周时不比较趋势，只使用已有的当前信息；可比较信息过少的案例不参与匹配。

**AI-M5：主表和消融表的完整记忆结果不同。**

**回复：** 旧数值不同的原因尚未查明，不能没有记录就归因于随机种子或设置差异。新实验中，同一方法在完全相同条件下的结果，将直接由同一批保存记录生成两张表。确实采用不同设置或重复次数时，必须明确注明。

**AI-M6：“theory/notheory”和“expert knowledge”术语不一致。**

**回复：** 图、图注、图例和正文应统一使用“with expert knowledge”和“without expert knowledge”，直接说明比较的是有无专家知识，避免让读者误以为是在讨论理论保证。

**下一阶段改进重点**

1. 核对旧感染总数、两张表的数据来源、实际模型和真实 API 调用记录；无法复现的结果应更正。
2. 用不参与最终测试的模拟完成基线训练和阈值调参，在最终比较前固定参数、提示词、历史案例、评价权重和模拟时长。
3. 在同一批模拟疫情中逐一比较各方法，分别报告感染、各类干预负担、置信区间及训练和 API 成本。
4. 在不同感染与负担偏好下重新优化各方法；控制干预时间或负担后比较记忆效果，并单独检验专家知识。
5. 使用未参与校准的日期检验预测，检查参数为何接近搜索范围上限，分别陈述模拟场景迁移和真实世界验证。
6. 完成第二模型和失败案例分析，统一任务参数、单位、图表、相关工作和结论范围。
