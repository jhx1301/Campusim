**CEMAS：LLM 控制基线与泛化实验实施方案（2026-10-12）**

本文记录研究原则及必要系统迁移。它是待实施的研究方案，不是已取得的实验结果。2026-10-12 已按用户授权补充[推荐协议 v1](llm_recommended_protocol_v1.md)和[具体配置](control_protocol_v1.json)，动作档位、资源、观察、计数、种子与预算以该推荐协议为实施起点。已确认：暂无可靠单位成本资料；所有控制器执行时只使用可观测数据；允许仿真真值用于源域离线奖励和最终评估，但不进入决策观测、LLM 提示、检索键或案例反馈。校准结果、实际模型版本和计算预算须由源域拟合/验收产生，不能把建议值写成已取得结果。

**1．研究问题围绕自主控制架构，分别检验控制、记忆和泛化。**

研究对象是部分可观测疫情环境中、具有短期经验组织与全局案例检索的 LLM 控制代理。人口个体由 ABM 模拟，干预由一个中央控制器选择；不将它表述为多智能体强化学习。

主研究问题：在相同观察、动作和资源约束下，双分支记忆 LLM 的控制与干预负担权衡如何？源域建立的控制器冻结后，能否适应城市网络与回合内资源变化？哪些记忆组件提供增益、哪些情况会失效？

论文不预设 LLM 获胜。只有数据支持时才能写“在所测试条件下改善了某项结果或权衡”。城市转移与资源解锁须独立实验；不同时改变场景和资源。组合动作作为共同任务接口，本轮不单独声称动作空间设计本身是新的算法贡献。

JAAMAS 包含自主决策架构、学习适应与实验平台，因此该定位符合其范围，但补基线和城市实验不能保证录用。相关工作应实质比较疫情自适应控制、经验检索代理以及反馈型 LLM 代理。

**2．所有方法共用一个可观测、可执行的任务协议。**

每 7 天决策一次，读取截至决策前一日已交付的信息。检测结果按报告延迟进入观察，不能使用尚未交付的未来诊断。主实验共享最近 4 周的观察与已执行动作历史；首次决策的空历史有明确填充与有效长度标记。

| 可以进入观察 | 不可以进入观察、检索或提示 |
|---|---|
| 新报告诊断、已实施检测、已知隔离/检疫人数及趋势 | 真实新增感染、暴露/感染者真实状态、真实患病率 |
| 诊断增长率、诊断与检测数量比的代理值 | 诊断数/真实感染数、仿真真实 R_e |
| 当前组合、各维持续时间、公开资源容量和合法动作 | infection_log 中真实传播来源、真实传播层贡献 |
| 人口总量、公开场景结构、预先公布的干预参数 | 本次仿真抽样的隐藏传播参数、未来事件日期或未来轨迹 |

诊断/检测比受报告延迟和重复检测影响，称为代理指标，不称为准确阳性率或患病率。首版不新增 R_e 估计器，也不新增传播层归因估计器。真实数据可由独立分析器读取，仅用于奖励、拟合和事后评价。

按用户最新授权，由推荐协议设定五维动作 [T,S,C,E,A]：病例相关检测3档、普通筛查4档、接触追踪3档、学校教学限制3档、其他机构/社区活动限制3档，共324组合。隔离/检疫保留共同固定处置。S请求量为0/0.02N/0.05N/0.10N，外部容量决定合法档；学校与其他活动分别选择。完整参数与校园/城市映射见推荐协议第3节。LLM输出强度向量，PPO/DDQN输出联合编号，二者解码到同一动作，不给RL缩成旧套餐。

若 M 为百量级，PPO 与 DDQN 都使用联合离散编号，便于共享完全一致的合法动作掩码。若实际 M 达到数万以上，应在训练前重新审查完整枚举的探索成本；这不是当前已确认的数据。

合法性只依赖公共动作定义和当前资源。首版每周自由切换，不保留旧保持期/升降幅度护栏；删除真实感染阈值以及LLM自报风险专属豁免。非法输出先保持当前合法组合；容量下降时仅把S投影到最高合法档。每次记录请求动作、执行动作、调整原因和回退。

**3．主比较选 PPO、Double DQN 和调优阈值，保留两个简单参照。**

| 方法 | 作用与实现 |
|---|---|
| 完整 LLM | 现有专家知识、短期经验组织、只读全局案例检索；适配公共观察及组合动作 |
| 无显式经验记忆 LLM | 保留相同专家知识与公共 4 周观察/动作历史，关闭短期经验组织和全局检索；在主表直接显示记忆的贡献 |
| PPO | 联合离散动作与合法掩码；输入公共 4 周历史、当前动作和容量，优先采用现成 MaskablePPO |
| Double DQN | 每个联合组合一个 Q 值；经验回放、目标网络、Double 更新；使用与 PPO 相同的历史和动作编号 |
| 调优阈值 | 每维使用公开的诊断/检测/负担指标与升降阈值；在源域验证集搜索阈值及迟滞，按共同目标选参数 |
| 最低干预参照 | 固定最低允许组合，遵守常规病例处置；准确命名，不把已有常规检测称为零干预 |
| 最高可行干预参照 | 每周期执行当前合法的最强预定组合，用于展示持续强控制的代价与收益 |

DDQN 的随机探索、贪心选择以及下一状态 bootstrap 都必须排除非法动作，回放中保存下一状态的合法性信息。存在多个最强而不可比较的组合时，预先固定简单参照组合，不根据测试结果选择。

本轮不增加MPC、Goal-DQN、推荐协议五维以外的动作或目标城市微调。所有未来会解锁的档位须在部分源域训练回合中实际可用并积累经验。

**4．训练借用负增量负担结构，但不虚构货币成本。**

参考 Mai 等的周闭环控制和疾病/干预负担奖励结构；原论文使用真实疾病状态与美元成本，因此这里明确称为适配方案，不称原样复现。由于没有可靠单位成本，不借用美元金额来宣称校园经济收益。

推荐固定尺度的训练目标：

\[
r_k=-\left[\frac{\Delta I_k}{N}+\lambda\,\frac{1}{4}\left(
\frac{\Delta T_k}{S_T}+\frac{\Delta L_k}{S_L}+\frac{\Delta Q_k}{NH}+\frac{\Delta A_k}{NH}
\right)\right].
\]

其中 N 为总人口，H 为评价时域；I 是新增感染事件，T 是实际检测次数，L 是已执行追踪通知人次，Q 是隔离/检疫人天，A 是活动限制的等效人天。隔离与检疫重叠者每日只计一次；追踪重复通知若确实发生，按工作人次记录。A 根据预先规定的活动对象和强度映射计算，不能把传播概率下降直接解释为同等比例人口被关闭。

S_T、S_L 使用训练前公开的参考日容量乘 H，不能使用参评策略的最大结果，不能随城市测试或解锁后的当前容量变化。容量与成本代理是合成基准设定，需要写明。若没有追踪工作量日志，先新增计数，不用最终隔离人数假装追踪工作量。

主实验lambda=1，lambda=0.5和2仅用于中等校园敏感性实验。四负担等权是基准假设，不代表真实价值相等。推荐S_T=0.12NH、S_L=0.10NH，来源是固定临床/筛查参考量与独立通知工作量参考；活动预算和计数按推荐协议第5节落实，不从beta下降反推人口限制。所有偏好与尺度在最终测试前冻结，对应偏好的RL/阈值也须源域重新开发，增加的预算单列。

PPO、DDQN、调优阈值使用同一目标；LLM 提示明确列出同一目标、参考尺度和偏好。LLM 的源域案例仅呈现可观测反馈与负担，不含隐藏感染真值。真实感染允许用于 RL 源域奖励以及控制器开发阶段的仿真目标计算，但测试时不作为任何方法的在线输入。

不额外用很大的切换惩罚制造 LLM 稳定性优势。主奖励不计切换，作为独立结果报告；只有确认实际切换成本或公开共同约束后，才纳入目标。

PPO/DDQN主设gamma=1，对应有限时域未折扣总负担。总回报不是最终排序指标。首版112个实际执行日（n_days=111），所有场景共同窗口；按推荐协议第12节的源域终点门槛统一延长至140/168天，全部方法重算尺度并重新源域开发后冻结，不能查看目标测试后选择性延时。

**5．源域只训练/调优一次，目标测试冻结。**

训练域为12000代理的合成校园，pop_scale=1、rescale=False、初始感染30、无再感染/疫苗/外部输入。beta相对E0校准中心U(0.85,1.15)，静态筛查容量从0.02N/0.05N/0.10N等概率抽样；回合内不变，源域不包含城市或中途容量跳变。公共观察告诉当前容量，不告诉本次beta。对所有档位做执行覆盖审计。E0拟合人口生成配置和控制基准人口配置分开记录，不把12000合成总人口称真实大学12000学生。

训练、验证、记忆采集、最终测试的运行标识与种子预先分开。模型选择、提示调整、阈值搜索和奖励参数检查只能使用源域训练/验证资料。LLM 全局库可以来自源域采集轨迹，但须记录其采集政策、数量和参数范围；不能含验证/测试轨迹。训练与记忆构建的成本分别披露，不声称 LLM 预训练与 RL 仿真训练具有相同总成本。

至少 3 个独立 RL 训练种子，预算允许时 5 个；不选最好训练种子代表算法。训练步数根据源域验证曲线及预先设定的预算确定。先计时小规模运行，估算仿真天数、训练更新和 LLM 调用开销，再固定预算。原论文的 30,000 周决策步只作为参考，不能当作 Campusim 收敛保证。

测试冻结 RL 权重与归一化参数、阈值、LLM 提示模板、模型版本和全局记忆库。允许各方法正常读取当前观察和更新本回合历史；禁止测试微调、根据结果改模板、向全局库追加目标经验。每个测试回合结束清空短期记录。

**6．实验按能力拆分，主结果不做全因素笛卡尔积。**

| 编号 | 研究问题 | 场景与方法 | 固定因素、改变因素 |
|---|---|---|---|
| E0 | 模拟器和计数能否支持后续结论？ | 公开资料重建的校园诊断序列；校准拟合与可行的时间留出 | 披露重建来源和精度；报诊断曲线、多运行范围、MAE/RMSE、精确人口与感染定义；不是控制器胜负实验 |
| E1 | 基本闭环控制是否有竞争力？ | 低/中/高校园条件；全部主比较方法 | 静态资源、相同动作与观察；仅使用未参与开发的测试种子 |
| E2 | 哪个记忆组件有效？ | 一个预定校园条件；无经验记忆、仅短期、仅全局、完整四种 LLM | 模型、专家知识、观察历史、动作、种子一致；只改变显式记忆组件 |
| E3 | 校园经验能否冻结迁移到城市？ | 两个预定合成城市配置；全部主比较方法 | 动作含义、疾病参数范围、静态容量、观察协议保持一致；改变网络和人口结构；不加解锁事件 |
| E4 | 能否响应未见的动态资源变化？ | 固定校园；全部主比较方法；筛查低容量中途提高 | 场景保持不变；只改变可用筛查资源；档位已在源域训练过 |

E0至少给出重建每日诊断序列拟合；数据不足可信留出时仅报告拟合证据，不称官方原始逐日数据或真实预测验证。推荐只校准全局beta并固定层权重，避免短序列中beta与全部层倍率的尺度冗余；独立种子评价，产物供源域读取。后期无干预反事实不能直接与已干预观测构成普通留出验证。核查人口、缩放、初始感染和再感染假设，不把感染事件默认解释为独立感染人数。

E1 采用已校准范围内的低/中/高条件，不把源域新随机种子称为分布外泛化。

E2 复用 E1 的完整与无显式经验记忆 LLM 结果，只新增仅短期、仅全局两组。“无经验记忆”版本仍获得所有方法共享的 4 周观察/动作历史，不只给它瞬时信息。短期模块检验历史经验的组织与压缩，全局模块检验源域案例检索。尽量控制检索条数与上下文配置，报告实际 token；信息与上下文长度不一致时限定因果解释。若保留专家知识改善稳定性的独立主张，只在此校园条件补一个去专家知识版本，不扩展全部矩阵。

E3 用 hybrid 的家庭/学校/工作/社区网络作为合成城市起点。主实验人口总量与源域保持一致，避免额外规模因素；城市年龄和网络构成可变化，疾病参数取源域范围。所有策略需具有相同含义：例如学校限制不能在城市中悄悄改成全体人群居家办公。机构限制的人群和执行映射提前公开。未进行城市真实数据校准时，只能支持合成场景迁移，不能支持现实城市效果。

E4 优先使用已有周期筛查的 daily_capacity 参数，事件明确称筛查资源增加，不称总检测能力增加。症状检测与周期筛查的资源边界分别定义，防止绕过容量。不同源域回合曾静态开放过高档位；测试首次出现回合内低到高变化。所有方法在同一决策日收到容量与合法集合更新，不提前知道事件时间。

E4采用day0–27共同最低干预和低容量，day28共同接管，主解锁day42、补充day56。接管后一直低为0.02N，待解锁组从0.02N升到0.10N，一直高组从day28即0.10N；避免待解锁和高保持在接管瞬间相同而重复。低保持与待解锁在事件前重放同方法的共同实际动作前缀并核对状态；各方法同公共近期历史，事件日期隐藏。测试种子不按收益或疫情是否消退筛选。主要统计接管后，事件效果配对比较升高与一直低；详见推荐协议第11节。

两个小规模补充即可：在一个校园条件检验 lambda=0.5/1/2（各目标只在源域训练，随后冻结；不为每个城市/事件重训）；另一种 LLM 在一个校园条件和一个城市条件复核。新增模型单独记录真实型号/版本，采用相同公共任务和源域资料边界。完整四分支消融不必在所有场景、模型和偏好上重跑。

如果未来把“组合动作优于固定套餐”写成论文贡献，再做同算法、同环境、仅动作集合不同的单独实验；本方案将组合动作视为共同任务条件，因此不增加该实验。

**7．评价以原始结果及权衡为准，不使用 CPBU 排名。**

| 类别 | 指标与解释 |
|---|---|
| 疫情 | 累计新增感染事件/总人口、每日感染峰值；诊断仅作辅助观察结果 |
| 运营 | 检测次数/人口、追踪通知人次/人口、隔离/检疫人天/人口 |
| 活动 | 等效限制人天/受影响人口，分别展示学校/工作等活动类别；全线上天数不是唯一负担 |
| 决策 | 决策周期上的各维切换次数、强度变化总量、非法输出、回退和护栏调整率 |
| 代价 | RL 源域训练仿真量和时间、记忆采集量、LLM 调用/token/延迟、每次推理时间 |

初始感染数作为公共环境常量单列。若模型允许再感染，明确感染事件可以超过人口，并另报独立感染人数；不将两种统计混用。不同场景的人口和时域归一化规则固定。

每个测试条件先采用共享的 20 个世界种子，覆盖人口网络和疫情随机性；如源域方差表明区间过宽，先提高样本量再冻结最终测试计划。LLM 和 RL 控制器的随机流与仿真随机流分开。共享 seed 只是匹配初始条件和随机生成协议，不保证干预后完全相同的随机路径。

RL 同时统计训练种子和测试世界种子的变异，采用分层/配对 bootstrap 的 95% 区间；时间点不是独立样本。以完整 LLM 与 PPO/DDQN 的预定差异作为主要比较，不对全部小格子逐个做显著性检验。

同一场景内，若一种方法感染和各项负担都不更差且至少一项更好，可以讨论支配关系；若指标方向冲突，称为权衡。不能仅因感染更少或切换更少就称总体更优。跨城市与校园不直接比较原始感染差来定义泛化退化，应结合场景内固定参照及源域/目标域结果分别解释。事件第一次使用高档位的延迟是行为描述，不默认越短越好。

若要声称相近负担下仍有感染优势，必须提供预先规划的负担匹配对照或权衡曲线；不能只引用训练代理总和或事后挑选相近点。

**10．论文结论与投稿材料由证据决定。**

可检验的结论模板是：在仅有诊断、检测等公共观察的情况下，双分支经验记忆在某些控制或迁移条件下改善了感染与干预负担之间的权衡；源域控制不一定最优，但冻结迁移或资源适应可能具有不同优势；消融说明哪些经验机制有效，并给出失效边界。所有空位以真实数值、区间和具体条件填写。

若 LLM 没有稳定优势，不能换权重、筛种子或改场景制造胜出。需要判断是负担权衡不同、机制没有增益、源域训练不足还是观察不足，再决定是否还有足够的架构或基准贡献。仅比固定阈值强、或只有单个综合分数更高，不足以支持强结论。
