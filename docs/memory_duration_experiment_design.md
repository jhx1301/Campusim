**记忆与干预持续时间：补充实验设计**

本文件是针对 review 的研究方案，尚未实施或运行。不修改当前五维动作、七日决策、公共信息限制、主实验或校准协议；下述新增对照需单独实现与验收后才能用于论文。

**首先明确研究问题**

“记忆推理”和“更长干预”不是两个天然独立、可以直接拆百分比的原因。按当前系统的设计，记忆通过改变干预决策影响疫情，延长持续时间可以正是它发挥作用的一条路径：

记忆 → 措施、时机、强度和持续时间的变化 → 疫情与干预负担。

后续疫情又会影响下一次决策。因而，应区分：

1. 加入记忆后，整体感染和各类负担发生什么变化？
2. 简单规定“晚一点放松”，能否取得相近效果？
3. 干预总量相同时，记忆能否帮助选择更有效的执行时机？

如果把每个时点的全部实际干预和环境随机过程都固定，记忆在这个模型中没有另外影响疾病传播的通道。这样的对照不能衡量脱离动作的“纯推理收益”。反之，同样干预总量下的收益差异仍可能来自时机或配置的改变。

**实验一：保留完整任务，比较三组**

| 组别 | 如何决策 | 回答什么 |
|---|---|---|
| 不增加显式记忆 | 保留共同的四周基础观察，不提供额外历史摘要和检索案例，正常选择措施 | 没有新增记忆模块时的表现 |
| 不增加显式记忆，加延后放松规则 | 使用相同 LLM；当它建议降低教学或其他活动限制时，按事先确定的规则再维持原档位若干完整周 | 简单的持续控制能否复现记忆组的效果 |
| 完整记忆 | 增加近期摘要和历史案例，其余条件与第一组一致，正常选择措施 | 新增记忆的整体效果 |

共同条件：同一模型及调用设置、专家知识、基础观察、输出要求、合法动作与执行规则、模拟时长和配对初始条件。不同决策造成的后续观察自然不同，不强行复用分叉后的观察。各组均只使用允许控制器看到的信息，真实感染和未来疫情仅用于事后评价。

延期规则是预先定义的简单对照，不使用记忆组在最终测试中产生的未来日程。可在开发模拟上比较延后一个或两个七日周期，再选定一条规则用于最终测试。明确延期触发维度、档位、何时到期及是否重新触发，不能每周无意重置计时导致永久保持。其他动作按该组控制器的正常建议执行。所有实际执行措施必须回到下一次公共观察和记忆记录中，不能把被覆盖的提议当作实际行动。

结果报告感染、峰值、终点活动感染和末期新增感染，同时报告各教学/活动档位天数、相应限制人天、实际检测量、通知量、隔离检疫人天及切换。不要把五维动作压成一个未定义的“严格干预天数”。

判断方式：

- 完整记忆减少感染但增加大量负担：支持更强控制下的收益与代价，不能直接说效率更高。
- 简单延期组以相近负担取得相近感染结果：尚不能证明复杂记忆优于简单的持续控制规则；“相近”需事先说明实际差异容忍度，或报告区间而不宣称等效。
- 完整记忆在感染更少的同时，所有预先关注的负担均不更高：支持更有效的策略选择，仍需说明估计不确定性。
- 一些负担更低、另一些更高：如实报告权衡，不重新构造 CPBU 来宣布总体赢家。

这些对照是明确策略之间的比较，不把两个感染差值相减后直接命名为“纯推理贡献”。延期规则不同，得到的差值也可能不同。

**实验二：固定教学限制总量，只让模型选择时机**

这是新增的补充诊断任务，不代替原五维自由决策的主实验。

为使解释清楚，先只研究教学这一维。对同一初始人群，两个组都必须使用相同数量的完全远程教学周，其余周正常线下教学；其他四维动作由同一个预先固定的规则或日程决定。比较不增加显式记忆与完整记忆两组。

例如，可以预先安排每组恰好使用四个完全远程教学周，即28天。这个数字仅为设计示例，应依据开发模拟在最终测试前确定，不能把某次记忆组测试得到的时长当作另一组的配额。两组自行决定在哪些周使用这四周限制，因而总量相同、时机可以不同。

两组都应知道剩余配额和剩余周数；控制机制应保证最终用量相同。只设置“最多四周”的上限不能保证实际用量一致。若不要求用完，就只能称为同一资源约束下的比较，仍须单独报告实际用量。

在现有活动负担实现中，教学限制人天由固定人口登记中的学校时间权重之和乘以教学限制比例逐日累计，见 [execution.py](../cemas/control/execution.py:359)。因此，同一初始人群、相同教学档位及相同总天数，可以控制该名义教学负担；实施后仍需按日志核对。

该实验中，若记忆组感染更少，可以说“在相同教学限制总量下，记忆帮助选择了更有效的时机”，不能再把差异解释为教学限制总天数更多。但不能因此声称所有干预负担相同：即使检测、追踪规则相同，实际检测量和隔离检疫人数仍可能随疫情改变，需要照常报告。该实验也不证明模型内部推理过程是忠实的。

此任务需要新增公开的配额信息和约束处理，现有代码未验收这些能力。实施前应明确观察、提示词、合法动作检查及历史案例适用规则，不通过绕过既有任务或来源检查完成实验。主协议和主实验仍保持原规则。

**可选实验三：在相同疫情状态下，检验多维持一周是否值得**

这项实验用于进一步了解延长发生的时机，可在前两项结果之后决定是否需要。

1. 先规定抽取哪些决策日期和初始条件，不按未来真实峰值或已知有利结果选状态。
2. 从相同的已执行历史生成相同公共观察，分别获得无显式记忆和完整记忆的提议，记录何时在是否放松教学限制上发生分歧。
3. 从同一模拟状态分成两条分支，分别维持当前教学档位一周和放松该维度，其他当前动作相同。
4. 一周后，两条分支都交给同一个事先固定的控制规则，再观察预先确定的后续时段。后续决策可随各自疫情改变，但使用同一条决策规则。
5. 比较这一周额外教学限制带来的新增限制人天与后续感染变化，检验记忆是否倾向于在延长更有价值的状态下提出维持。

分叉必须保留完整模拟状态、待交付事件和所有相关随机状态；简单 deepcopy 并不能保证这一点。两条分支的随机数安排应预先定义，重复模拟评估随机误差，不能声称不同动作下每个个体的随机路径必然相同。

这测量的是指定状态下“额外维持一周”的影响，以及记忆建议与该影响的对应关系。由于各周决策互相影响，不能将这些局部差值直接相加为整个回合的感染下降，更不能直接换算成“推理占比”。

**分析与样本安排**

- 第一项的无记忆/完整记忆两组可复用主实验中完全相同的运行记录。附加延期组和等量教学任务单独登记，不能冒充原任务的主结果。
- 可沿用20个配对初始条件作计划起点，但不把20视为保证统计功效的数目。模型调用若有明显随机性，应在开发模拟上决定额外重复次数，而非看最终显著性后继续加样。
- 以初始条件为比较单位，报告各组差异和置信区间；不能把每周或每天当成独立样本。各重复调用及模拟随机性如何计入区间，应预先说明。
- 延期规则、教学配额和随访窗口均在最终测试前确定，不根据测试赢家调整。所有失败、实际覆盖动作和末期疫情都保留。
- 不在实验后仅挑出“实际干预天数相近”的回合再作因果比较，也不简单把天数加入回归后将剩余差异称为推理效果。疫情严重程度会反过来影响后续持续时间，需对这样的时间反馈作专门处理。
- 若主实验两组已有对应记录，新增一个延期规则和一个教学配额、每条件20个初始条件，共新增20+2×20=60个回合。若共同任务为112天，每回合16次决策，最多新增960次按周模型决策，未计重试。此为计划数量，不是已发生调用，也不表示已授权运行。

时间变化下的中介分析与其识别限制可参见 [VanderWeele and Tchetgen Tchetgen, Mediation analysis with time varying exposures and mediators](https://pmc.ncbi.nlm.nih.gov/articles/PMC5560424/)。上述模拟对照是本项目的拟议设计，不是该论文直接规定的实验方案。

**可用于回复审稿人的表述**

更长干预可能是记忆发挥作用的途径，因此现有结果不能自然拆成“推理”和“时长”两个贡献比例。我们将保留自由决策的整体比较，并补充无记忆但延后放松的对照，以及教学限制总量相同、只允许选择执行时机的诊断实验。前者检验简单持续控制能否复现收益，后者检验同量教学限制下的时机选择是否更有效。各项感染结果和干预负担将分别报告，不将差异直接解释为模型内部推理的独立贡献。
